# 界面规范

所有页面共用一套规则，以 Claude 桌面应用为唯一参照（团队会话保留飞书的结构，视觉语言相同）。复用 `frontend/src/ui` 组件，数值使用 `frontend/src/ui/tokens.css` 中已有的变量，不新增尺寸变量，不写裸数值（1px 边线除外；媒体/容器查询断点保留字面量）。

## 外壳与表面

- 外壳（`--ui-bg-1`，暖色）上放 rail 和侧栏，它们没有自己的底色；打开的页面是一张浮在外壳上的卡片：四周留 `--ui-space-8`（贴侧栏的一边除外），圆角 `--ui-r-16`，`--ui-elev-1`。
- 页面根元素用卡片色 `--ui-bg`，不要再铺 `--ui-bg-1`；`--ui-bg-1` / `--ui-bg-2` 只用于卡片里的嵌入块。
- 输入框（首页、研究线程、团队会话）是同一种：`--ui-elev` 底、`--ui-r-20`、`--ui-elev-composer`，聚焦时边线加深到 `--ui-edge-strong`。
- 首页问候语用 `--ui-font-display`（衬线），`--ui-text-30`，regular。
- 深浅两套都来自 tokens.css 的基础色板；本机版不再覆盖颜色。
- 验收：参照截图和 ORA 截图在 1440×900 下并排，逐项比间距、字号、字重、颜色、圆角、图标。

## 文案

- 只有名称、状态、按钮文字。不写引导段落、副标题说明、字段提示（description）、空状态描述、括号里的解释。
- 按钮用动词：「新建任务」「导入」「保存」。确认类对话框只问一句：「删除这个任务？」。
- 状态用短词：进行中、等你、已完成、已暂停、失败。
- 错误只说发生了什么和原因，不说怎么办，除非有一个按钮能办（「重试」）。
- 中英文两份文案同步：`frontend/src/i18n/messages/{zh,en}.ts` 同时提供对应键。

## 字号和字重

- 页面大标题（分区主区的 h1，如「全部」「定时任务」「插件」、设置页标题）：`--ui-font-display`（衬线），`--ui-text-24`，regular。
- 对话页顶栏标题：`--ui-text-14`，strong。
- 正文和对话：`--ui-text-14`。
- 侧栏条目、列表行、按钮：`--ui-text-13`。
- 次要信息（时间、计数、元数据）：`--ui-text-12`，颜色 `--ui-fg-2`。
- 侧栏分组标题（项目、最近）：`--ui-text-12`，`--ui-fg-3`，不加粗。
- 只用两种字重：regular 和 strong。

## 间距和尺寸

- 只用 `--ui-space-*`。页面主区左右内边距 `--ui-space-32`，顶部 `--ui-space-32`；大标题和下面内容之间 `--ui-space-24`。
- 侧栏条目高 `--ui-control-md`（32px），列表行高 `--ui-control-lg`（36px）以上。
- 主区内容最大宽：对话用 `--ui-conversation-width`，列表和管理页用 `--ui-page-width`，居中；团队画布铺满可用主区。
- 圆角：按钮和字段 `--ui-r-8`，卡片和面板 `--ui-r-12`，页面卡片和对话框 `--ui-r-16`，消息输入框 `--ui-r-20`，胶囊 `--ui-r-pill`。
- 计数文案用 `tn()` 和 `#one` / `#other` 两种形式（英文「1 reply」「2 replies」）。

## 组件

- 按钮三种：primary（每个视图最多一个，放在主要动作上）、secondary、ghost。图标按钮必须有 aria-label 和 tooltip。
- 页面右上角的动作区：搜索框（`--ui-control-md` 高的胶囊）+ 一个主要动作按钮，和资料页、定时任务页、自定义页保持同一位置和尺寸。
- 列表行：行首图标 16px、名称、行尾元数据或「⋯」菜单；悬停才显示行尾操作。
- 「⋯」菜单收纳次要和危险操作；危险操作标红，放在菜单最后，执行前确认。
- 空状态：居中图标（32px，`--ui-fg-3`）、一句短标题、最多一个按钮。
- 对话框：标题一行，表单字段只有标签，没有说明；底部右对齐「取消」「主要动作」。
- 开关（switch）只用于立即生效的设置；需要保存的表单不用开关。
- 加载：先显示骨架或保留上一屏，不出现整页空白加转圈；按钮自身的 loading 状态用于提交。
- 图标统一用 lucide，16px（侧栏和按钮）或 14px（行内元数据），描边一致。
- 焦点可见：所有可交互元素有 `--ui-focus-ring`；键盘可以完成主要流程。
- 团队排队或运行中的消息在消息上提供「停止」；正文提及负责人只通知，不推断「等你」。

## 一致性检查表（每个页面都过一遍）

1. 大标题位置、字号和右上角动作区与其他分区一致。
2. 没有说明文字。
3. 没有点了没反应的元素：不能点的就不要长得像按钮或标签芯片。
4. 同一个动作在不同地方叫同一个名字、用同一个图标。
5. 浅色和深色都检查；窄窗口（720px）不横向滚动。
