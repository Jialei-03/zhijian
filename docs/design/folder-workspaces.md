# 文件夹工作区与研究会话

本文描述研究线程的实际执行目录；团队频道、私信和成员文件的关系见 [研究团队](agent-team.md) 与 [成员文件](agent-files.md)。底层使用 Pi 0.85.1。

## 产品关系

- 工作区是一台机器上的真实文件夹，绑定本机路径或 SSH 连接和远端路径。
- 界面统一称「项目」。侧栏新建和项目列表空状态直接打开新建对话框，默认在 `~/ORA` 下按必填项目名新建文件夹；初始名称「未命名项目」全选。`~/ORA` 不存在时创建，同名文件夹已存在则拒绝新建。「选择已有文件夹」为另一分段选项，从同一默认目录浏览。
- 项目目录拒绝根目录、用户主目录、系统目录（`/Users`、`/System`、`/Library`、`/Applications`、`/usr`、`/bin`、`/etc`、`/var`、`/private`）及主目录内 `Library`、`Desktop`、`Documents`、`Downloads` 本身，规范化路径和符号链接后校验；其下独立项目子目录可选。SSH 同样在远端规范化与校验，并在连接前拒绝 `/`、`~` 等明确的受保护路径。浏览仍可进入这些目录，提交按钮禁用并显示短原因。
- 每个研究会话对应一项研究，作为团队实验频道中的研究线程；普通频道和成员私信使用独立的团队运行。新研究页选择工作区、可选分类、工作流和模型，发送第一条消息才创建；没有额外的固定项目导师层。
- 项目 `ResearchCollection` 只分类，可跨工作区；归类、显示名和置顶不改变目录、机器或研究问题。
- 看板以 `ResearchProject.on_board` 为唯一收录依据，不自动加入地图节点或其他研究。
- 团队界面通过频道、私信和线程导航，计划、地图、实验、证据、文件和成果保留为研究配套记录。旧研究链接保持可访问。

## 运行和历史

定题与只读讨论保留同一研究的 Pi 会话条目。定题可用 read / ls / find / grep 查看绑定文件夹，禁止 bash / write / edit；实验仍需要人批准计划。自主执行、评审和提炼使用各自的新简报，事实由地图和交接传递。无 Pi 条目时回填对话会排除自主轮次的系统简报，不把它们伪装成用户消息。

研究暂停、等待决定或结束后仍能继续提问，只开只读 discussion，不恢复实验、不批准旧计划，也不为讨论拍摄可能属于别的研究的文件检查点。回答期间收到的新问题按消息边界进入下一轮。复盘与同会话讨论不能同时启动。

本机工具和实验的 cwd 是所选文件夹。SSH 工具和作业在绑定远端目录执行，连接支持端口、身份文件和 BatchMode；不会自动接受未知主机密钥。SSH 文件页展示最近同步的快照，不能冒充实时远端目录。源目录丢失时失败，不自动新建替代目录。共享外部目录的写入研究串行调度；独立分叉有自己的工作树。

Pi 会话的工具 cwd 与 Node 的物理隔离目录分离，系统提示显示真正的执行目录；SSH 分叉的 `~/...` 在同一远端连接上规范化为绝对路径。资源加载器仍使用本机隔离目录、空 agentDir 和内存设置，不读取同名路径的本机 Pi 配置。侧栏、工作区选择器和研究目录栏同时展示机器名称，避免只看到目录却不知道在哪台机器执行。

SSH 分叉先从检查点复制到自己的远端目录。作业结束后先拉取有界临时快照，再导入应用持有的本机私有 Git 工作树，远端删除也会进入检查点；同步不向用户目录执行 `rsync --delete`。Shell 作业用独立换行包裹子 Shell 并记录退出码，保留没有末尾换行的 heredoc 终止符。

## 检查点与成果写回

用户 Git 不参与自动提交。代码检查点从真实目录复制到应用私有仓库，忽略 .git、数据、环境、依赖、权重、符号链接和超限文件；分叉使用精确保存的地图、历史及代码提交。旧轮次没有真实快照时不能分叉。

团队普通成员在应用私有项目主工作树执行，成员定义 `.ora/agents/*.md` 与共享说明 `AGENTS.md` 也在这里；不为了打开成员页或运行普通频道消息抓取本机/SSH 源码。研究线程仍按上述真实目录或独立分叉语义执行。

成果合并预览先刷新私有 main 的目录镜像，再做所选文件的三方差异。预览保存真实目标路径、SSH 连接描述、文件内容摘要、权限和根目录身份。应用前重检这些状态；变化则拒绝并要求重新预览。确认后创建带 ORA-Merge 标识的私有 Git 提交，再写回真实本机或 SSH 目录，成功后记录独立发布回执。数据库失败或连接 ACK 丢失可用同一预览恢复，恢复只接受预览前状态或该提交的准确结果。

写回保留已有文件权限，只有显式执行位变化才调整 x；新文件以不覆盖现有目标的方式发布，失败回滚不会覆盖用户后续修改。已有文件采用最终内容复核与原子替换，标准文件系统不提供跨进程的内容比较并交换，不能承诺消除最后一次复核之后的外部写入竞态。

## 迁移与接口

0039 新增 workspace.location、ResearchCollection、研究 collection_id / title / on_board。原研究 ID、文件、运行与 Pi 条目保留；旧项目导师与普通项目聊天转换为暂停研究，并生成可见历史。迁移可重复执行；downgrade 保留新数据表和字段，旧 mapper 忽略额外字段，不删除分类或绑定目录。

- `GET /research/navigation`：按工作区列研究及项目分类。
- `GET /research/folders`：使用 kind / path / connection_id 参数浏览目录，返回 `project_error` 短原因代码。空路径定位到 `~/ORA`，仅默认目录不存在时创建；指定路径不创建目录。
- `GET/POST /research/connections`：SSH 连接列表、校验与保存。
- `POST /research/workspaces`：注册已经验证的真实目录；`create_folder: true` 时以 `location.path` 为父目录、`name` 为单个文件夹名原子新建后绑定。拒绝空名、路径分隔符、`.`、`..` 和已存在目标；规范化后同一用户不能重复注册同一位置。
- `POST /research/collections`、`PATCH /research/collections/{id}`：新建和修改分类；`PATCH /research/projects/{id}/organization` 更新研究分类、标题、置顶与看板成员。
- `GET /research/board`：仅返回所选研究。

旧普通聊天创建入口返回 410；历史读取入口继续可用。论文、通用聊天和未转换的兼容对话按 capabilities 保留复制、压缩等能力；已迁移研究使用自身消息和轮次分叉，不开放通用 clone / compact 或运行入口绕过研究状态机。会话控制见 [session-management.md](session-management.md)，分叉与成果接口见 [workspace-threads.md](workspace-threads.md)。
